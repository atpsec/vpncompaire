Android TV and Google TV boxes support Play Store — setup is similar to phone Android but with a TV UI. Pair with [Xbox/PlayStation](/blog/xbox-playstation-vpn-setup) and [Apple TV](/blog/apple-tv-vpn-setup) guides for full home theater coverage.

## Play Store VPN App

1. Open Google Play Store from Google TV home
2. Search your provider — NordVPN, Surfshark, ProtonVPN, etc. with Android TV builds
3. Install, sign in via TV-friendly UI (often QR login from phone)
4. Pick server and connect
5. Enable [kill switch](/blog/vpn-kill-switch-explained) if available

## APK Install (If Needed)

When Play Store lacks the app:

1. Download official Android TV APK from provider site
2. Enable unknown sources in security settings
3. Install via file manager

Only use official APKs — fake VPN apps steal data.
