Android offers both Private DNS and Always-on VPN. Used correctly, they can create a predictable mobile security baseline, but overlapping DNS settings sometimes cause confusing failures.

## Private DNS

Private DNS encrypts DNS resolution when a compatible provider is configured. It does not tunnel all application traffic.

## Always-on VPN

Always-on VPN can automatically keep a selected VPN profile active. Android can also block connections that do not use the VPN, which is useful for users who require strict tunnel enforcement.

## Common conflicts

A VPN may expect to use its own DNS resolver while Android is configured for a separate Private DNS provider. Some networks or captive portals may also fail until the strict VPN mode is temporarily adjusted.

## Test sequence

1. Record connectivity without the VPN.
2. Enable Private DNS and test.
3. Connect the VPN and run DNS/IP checks.
4. Enable always-on behavior.
5. Test Wi-Fi to mobile-data handoff.
6. Re-test after Android or VPN-app updates.

## Bottom line

Private DNS and Always-on VPN are complementary controls. The safest configuration is the one where you know which resolver is used and whether any traffic can leave outside the tunnel.
